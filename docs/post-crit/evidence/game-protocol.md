# Game spike protocol v1 — frozen before implementation/trials

22 October 2026. Technical comparison only, no participant preference or production reliability claim. Owner: game-spike lane. Parent chooses one game. Scope: isolated rule/authority probes and small DOM shells; no production server changes.

Common task: at desktop 1920x1080 and phone 390x844, read rules, Join or Watch, identify turn, make one legal pointer move and one keyboard move, see feedback, Leave immediately and Return to the existing study-card placeholder. Repeat two- and six-resident scenarios. Two-player games expose four watchers at six residents. Rules/actions vary; shell controls, original pine/paper/gold styling, viewport and task remain matched. Cards use actor-specific views only.

Measures: actual DOM viewport; primary game target bounding boxes and clipping; pointer/key activation counts for common actions; serialized command/public/private/full-state bytes; source lines/bytes; pure illegal/terminal/role/session/revision/controller/idempotency/restart/departure probes. Large targets are evaluated against a declared 44x44 CSS px project target, not a claim of standards conformance. Board squares may miss it; report honestly.

Rules baseline: four-in-a-row standard 7x6 gravity, first four horizontally/vertically/diagonally, filled board draw. Chess legal moves via pinned chess.js1.4.0; 180000ms each, no increment, persist initial position plus move history and remaining clocks. Explicit automatic library draw policy is a house-rule deviation from FIDE claims. Crazy Eights: Bicycle five-card deal; match rank/suit, wild eight chooses suit; draw one at a time until playable or empty; optional draw even when playable; pass only if stock empty and no legal card; no recycling; all-pass blocked round draw (declared house rule); first empty hand ends round. No cross-round scoring. Deterministic deck fixtures are NOT secure shuffling.

Authority fixture: six fixed member identities, server-supplied actor/controller/scope; session+revision checked; command-ID receipt stores payload fingerprint to distinguish accepted retry from changed-payload reuse. Session state survives JSON serialization. Explicit departure terminates the round with member-left, remaining participants may consent to a fresh round. Disconnect preserves state. This simple termination policy is a spike, not yet an approved lifecycle.

Stopping condition: one scripted trace per candidate/view/occupancy and bounded negative/terminal fixtures; repair mechanical/projection defects once discovered, rerun affected checks, then stop at about45min actual work. No repeated green trials or whole second app. Freeze source hashes with outputs. Native browser work waits for parent GO to avoid shared GPU contention. If inaccessible, keep browser NOT RUN and supply reproducible runner. Independent fresh review is parent-owned; no winner claimed solely from test count or source length.
