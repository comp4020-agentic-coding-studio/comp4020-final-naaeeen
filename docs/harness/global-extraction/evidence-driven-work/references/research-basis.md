Extracted7October2026 from the actual preserved A2 research report and active A3
REPORT/methods. A2's18paired exploratory runs remain historical project evidence;
they are not new trials or universal reliability proof. Its model/runtime/policy
pins and public-release rules were deliberately excluded.

Current checked sources:

- [Evaluating AGENTS.md v3](https://arxiv.org/html/2602.11988v3),29Sep2026,
  §§4.2–5: instruction files' effects depend on file source and benchmark; no fixed
  optimum cadence/length is established. Python issue-resolution scope limits transfer.
- [Agentless v2](https://arxiv.org/html/2407.01489v2): reproduction/regression
  filtering informs evaluator calibration; generated checks can fail to recognise
  valid reference repairs. This is not proof of a preferred current model.
- [Demystifying evals](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents)
  and [long-running app harnesses](https://www.anthropic.com/engineering/harness-design-long-running-apps):
  useful engineering cases for isolated trials, feedback and iterative evaluation;
  vendor cases do not establish universal reviewer cadence or superiority.
- [OpenAI instruction discovery](https://learn.chatgpt.com/docs/agent-configuration/agents-md):
  global instructions are layered with project instructions when a run begins;
  another host/custom Codex home requires its own installation.
- [Current local skill discovery](https://learn.chatgpt.com/docs/build-skills):
  use the session catalogue/path; user skills normally live under ~/.agents/skills.
  A supplied older skill-creator route suggested ~/.codex/skills; current primary
  documentation and actual catalogue scope informed this installation choice.
- [Personalization](https://learn.chatgpt.com/docs/personalize) and
  [desktop settings](https://learn.chatgpt.com/docs/reference/settings): custom
  instructions and mandatory project guidance differ from memories; desktop personal
  instructions use AGENTS.md. A local file edit does not establish synchronization
  to every web/mobile account surface.
- [Rethinking skills and prompts](https://developers.openai.com/blog/rethinking-skills-and-prompts-for-gpt-6-astra),
 11Sep2026: keep routing relevant; avoid indiscriminate doc stacks and redundant
 constraints. This model-specific advice does not override the owner's explicit
 preference for frequent meaningful comparisons and reviews.
