# Evidence and continuation

Keep project facts and runtime commands in existing project docs. The global entry
contains reusable defaults only. Do not import coursework deadlines, deployment
permissions, datasets, stack pins, credentials, personal reflections or historical
PASS states into other projects.

Use a compact record per meaningful subsection:

- User outcome/requirement and current candidate/source version.
- Uncertainty, alternatives and chosen comparison/check with predeclared acceptance.
- Actual source/environment/execution/result and attribution.
- Review context/findings; parent reproduction/reconciliation and disagreements.
- Refinement, affected verification, real commit if relevant and residual gaps.

Distinguish PASS, FAIL, NOT RUN, ABORTED and INFRASTRUCTURE FAILURE. Keep proposed,
retrospective and newly executed work separate. Human usefulness, aesthetic value,
student understanding and personal reflection cannot be inferred from test counts
or subagent agreement. Preserve source facts versus interpretation.

For long work keep objective, phase/subsection, decisions, ownership, changed files,
checks, active processes/freezes, blockers and next action in a short current handoff.
A hold needs reason, owner and release signal; continue independent authorised work.
Never silently change measured runtime bytes. Keep logical reviewable commit history,
preserving others' edits and required hooks. Never invent trials or chronology.

At phase/section exits reconcile the requirement with actual evidence before expanding.
Update the applicable methods for demonstrated recurring omissions; do not accumulate
universal defensive rules from every hypothetical edge case. If a route is wrong,
research alternatives and pivot with reasons, preserved user value and explicit cost.

Language and formatting follow the current user/project, not A3's English-only rule.
Resources may come from any relevant language. Communicate outcomes, useful evidence
and material limits concisely. User approvals persist in their actual scope.
