## Critical review and refinements

A read-only reviewer, previously used for an unrelated SQL cache review, inspected
this new topic without earlier global-extraction verdicts; this is contextual
qualitative review, not an independent agent-efficacy trial. Its three forward
scenarios covered a typo, uncertain architecture/performance and multi-phase
identity/private-state race. They exposed two corrections: host-aware skill
lookup and an explicit unavailable-review disposition. Parent checked current
primary sources and applied both. Unsupported hosts record labelled self-review,
actual checks, independent review NOT RUN and the residual gap; stricter project
gates remain intact. Small self-contained tasks avoid artificial experiments.

The default policy requires frequent useful comparisons and fresh reviews for
substantial decisions and each meaningful subsection. It does not require an
unlimited technique count or claim a measured universal performance benefit.
A2's18runs remain historical. No global-method efficacy A/B, human trial or
account-sync study was performed. The extraction omits course deadlines, stack/
Fly pins, historical PASS states, release permission and A3's English-only rule.

## Scope beyond the inspected hosts

[Official instruction discovery](https://learn.chatgpt.com/docs/agent-configuration/agents-md)
and [skill discovery](https://learn.chatgpt.com/docs/build-skills) explain local
loading and precedence. [Personalization](https://learn.chatgpt.com/docs/personalize)
and [settings](https://learn.chatgpt.com/docs/reference/settings) distinguish
personal instructions from memories. Existing current-session workers were not
restarted to pretend they automatically received a newly installed skill.

Web/mobile account synchronization and cloud/other-machine skill installation
were NOT RUN. [Portable custom instructions](CHATGPT-CUSTOM-INSTRUCTIONS.txt)
are provided for those account surfaces; no unsupported remote setting change is
claimed. Standalone local skills and plugin-distributed cross-surface skills have
different reach. User/project instructions can still supersede these defaults.

A future real reliability question can earn a matched isolated A/B protocol;
syntax validation and qualitative scenario review cannot substitute for it.
