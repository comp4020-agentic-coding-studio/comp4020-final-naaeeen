six floor items first, personal expression, one coauthored lantern/short note,
formal identity/rights, live withdrawal/revocation, realtime/resync, ordinary
restart/redeploy and mobile/keyboard. It has no banner/archive schema, commands
or UI. Full adds these only with complete retention/retraction contracts.

keys before exchanges; replay receipts/generations handle lost responses. A host
names a provisioned circle, not an unlimited public create endpoint. Assessment
uses two final unconsumed invitations and two free slots; rehearse with separate
identities. Repeated memorials use explicit occasion UUID, not undefined calendar state.
