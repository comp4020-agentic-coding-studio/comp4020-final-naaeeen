# Fresh comparison brief

Read only. Do not consult prior chat, mapping, main design drafts or other reviewers.
This is a small private browser neighbourhood for 6–8 existing friends, initially
around two weeks of individual development. Desired look: cosy warm light, pixel
edges and spatial depth. Important actions must also have normal text/keyboard
controls. DIY should feel expressive but use bounded catalogues/templates.

## Visual inspection

Inspect `screenshots/candidate-{M,N,P}-desktop.jpg` and their `-phone.jpg`
counterparts with view_image. They are full native viewport screenshots of a
working scene at 1920×1080 and desktop-emulated 390×844.
All represent the same saved placements and chair selection. The illustration
assets differ in one candidate, so this is not an isolated style experiment.

Capture amendment after first review: the original native crops were invalid
(incorrect portions or blank), and were retained as `rejected-crop-*`. Corrected
evidence uses full screenshots. View labels are visible: the corrected visual
pass is explicitly UNMASKED. The initial visual ranking is withdrawn because
evidence framing differed. Product reasoning remains useful. Do not count this
as a fresh re-randomized or fully blind trial.

For each: report specific visible strengths/problems and 0–3 ordinal scores for
warmth/readability, orientation/occlusion and phone identification. Treat DIY
clarity and extension as unknown where screenshots do not establish them.
Pick a provisional visual candidate; explain sensitivity to art and controls.
These are model judgements, not human preferences or predicted course marks.

## Product directions

Compare these equally specified concepts without opening the main plan:

- Q: Each friend has a window and bounded room decor. The courtyard has two
  jointly authored objects (a lantern and banner); each person edits their own
  visible pane/tile. Friends can contribute hours apart. Return shows meaningful
  object changes; an explicit semantic snapshot commemorates an occasion.
- R: Each friend has a window and bounded room decor. Windows advertise voluntary
  small help offers/requests; friends accept or decline. Shared space reflects
  finished favours and thanks. Requests expire without penalty or ranking.
- S: Each friend has a window and bounded room decor. Friends leave different
  perspectives on a shared event; a street object opens that multi-view memory.
  Authors can edit/retract their own entry. A limited archive keeps occasions.

For each: evaluate distinctive user value, return reason, burden/pressure,
two-week implementation scope, maintenance and a first small real-friends trial.
Give concrete objections, repairable improvements and recommendation. Do not claim
universal novelty, friendship benefit, retention or a statistically winning A/B.

Output a concise structured review with independent visual and product choices.
Completion is the review, with no file edits or remote changes.
