# Independent review 1

Reviewed candidate v1 before trial results. Three findings were accepted:

1. Protecting every existing assertion can preserve an incorrectly restrictive test. Candidate v2 distinguishes the real requirement from its fallible implementation and calls for valid/invalid cases.
2. Unconditional plan updates and local commits can exceed a read-only request. Candidate v2 scopes them to authorized implementation.
3. A blanket ban on unsupported learning outcomes can block curriculum design. Candidate v2 permits proposals within the brief while keeping source facts and observed evidence honest.

These are static risk assessments, not observed A/B failures. The reviewer found no reason to remove the course, viewport, student-authorship or external-action boundaries. Numerical self/peer ratings are not used as empirical scores.

Candidate v1 remains saved; v2 is the first candidate to enter runtime evaluation.
