# Process overview

I think a good AI agent session needs a solid working framework, so research into agent practices and CLAUDE.md came first. Sword Art Online first drew me to computing. I wanted After Aincrad, a history course set in 2035, to make its events understandable to newcomers. Before building content, I asked Codex to research OpenAI and Anthropic guidance, studies of instruction files and practitioner methods. The sources, report, candidate instructions and trial results are saved in [the harness research folder](docs/harness-research/README.md). My starting point was the Crit 5 instructions that Claude had adapted during setup ([0b50b24](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-Naaeeen/commit/0b50b24)).

The rules we compared were CLAUDE.md directions: which files to read, when to plan and how to check work. Codex compared research-based revisions with the original on small repository tasks. Across 18 scored runs, each pair started from matching project copies; only CLAUDE.md differed. Model settings stayed fixed. We kept browser checks, added independent review, required planning for uncertain changes and limited reading to relevant files. We removed duplicate build instructions. I required the agent to follow the selected rules; AGENTS.md directs Codex to CLAUDE.md before editing ([2b885c8](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-Naaeeen/commit/2b885c8)).

The evaluation checked behaviour as well as code: preserving existing edits, leaving files untouched on read-only tasks, and reporting checks honestly. We fixed criteria before comparing outputs and kept the judging code outside the trial copies, checking it for changes. All 18 results passed its automatic checks. A separate agent reviewed outputs without version labels and spotted a false pass: text resembling a link counted even when nothing was clickable. The main agent reproduced this and replaced text search with checks of real HTML links, verified against 31 valid and invalid cases ([785b1ce](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-Naaeeen/commit/785b1ce)).

Implementation followed that loop: research, plan, build a small part, compare, review and update instructions. Agents owned separate teaching, source, interface and slide files; the main agent checked their findings. We compared homepage layouts using the same material and completed one teaching week before expanding ([800ed14](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-Naaeeen/commit/800ed14), [4fc9cde](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-Naaeeen/commit/4fc9cde)). Three documents guide the tutor through this work: the [goals file](docs/planning/implementation-goals.md) requires research, A/B comparisons, verified subagent feedback, browser checks, CLAUDE.md updates and five human checkpoints; [implementation research](docs/IMPLEMENTATION-RESEARCH.md) records sources and choices; [process evidence](docs/PROCESS-EVIDENCE.md) links problems, fixes and commits. I required the agent to follow these goals and maintain the records; PLAN.md carried tasks and check status ([c14d959...8d518f9](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-Naaeeen/compare/c14d959...8d518f9)).

For me, a good course should make the next learning step clear while keeping useful material easy to revisit. I wanted students to follow SAO as history from 2035 across the whole teaching sequence, with explanations for newcomers and source credits available without interrupting every account. I rejected categories that made students guess where learning began. I also asked to keep the atlas, slides and other important pages visible. A guided route with direct resource links met both needs: newcomers could follow “Start here” into weekly preparation, the seminar and follow-up; returning students could open a resource directly. Putting everything in a catalogue would still leave the sequence unexplained, while hiding resources behind the route would make revisiting them harder ([17ef14d](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-Naaeeen/commit/17ef14d), [9741b89](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-Naaeeen/commit/9741b89)).

Before moving on, I needed evidence that this route worked. The agent's phone check found the week selector below a long introduction; after revision, the first action and week choices fitted their pages' first screens. Browser checks followed Week 9 to its assigned Week 2 notes and back. CLAUDE.md gained first-action and returning-student checks; spec/ protects preparation order, time totals and meeting details. I then asked to proceed to submission preparation. I kept coherence, voice and appeal for human review: working links cannot establish whether the history makes sense to a newcomer or feels worth studying ([9741b89](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-Naaeeen/commit/9741b89)).
