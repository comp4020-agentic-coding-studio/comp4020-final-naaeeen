## Cadence

Before each vertical phase, read its applicable active rules and acceptance.
Before each substantial commit, reconcile source/diff with those rules, actual
checks and independent findings. At every phase exit, record evidence and remaining
gates. A failed test, disputed agent claim, new privacy boundary or changed source
triggers an affected-section audit. Use focused sections; historical A2 experiments
are reference material, not executable current tasks.

Parent owns integration and reconciliation. Independent review starts without
parent chat history for a new consequential candidate. Follow-up review explicitly
retains context. Controlled comparisons define common inputs, criteria, versions
and stopping conditions before execution. No technique is treated as success
merely because its name appears in the worklog.
