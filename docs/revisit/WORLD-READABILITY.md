The implementation separates actual avatar coordinates from projected screen
rectangles. Shifted tags and bubbles retain player IDs and explicit speaker names;
leader lines point to the actual projected actor anchors. Cached dimensions are
read in one batch after changes and updated by a shared ResizeObserver, rather
than interleaving forced reads and writes for each label each frame. Routine
packing is bounded to 189 candidates per label and a 100 ms cadence; genuine size/text/
control changes invalidate the cache. Candidate ranking is deterministic. Tags
follow their original avatar anchors rather than parking while the person moves.

Speech uses only newly delivered, higher-sequence IDs within one authorised
scope. Initial/reconnect/zone/controller/access/epoch state establishes a baseline.
One latest preview per connected same-zone member lasts four monotonic seconds;
at most the three newest are shown globally. Quiet clears/suppresses all previews,
including self. Body text is at most 80 Unicode codepoints, plain DOM text, under one
attributed header with a visible Chat hint; the body occupies one clipped visual
line. Seen IDs are capped at 400, active preview state is bounded by current members,
and revocation/dispose clear it. Full conversation/ACK/unread remains native UI.
