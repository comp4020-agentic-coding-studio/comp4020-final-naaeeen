# Night Neighbourhood living plan

Updated6October2026. This is the active plan after runtime evidence and the
owner's interface feedback. Imported Chinese research/previous plans remain
byte-preserved history under docs/planning-source.

## Product and presentation

Personal windows/rooms and identifiable parts of jointly authored objects in a
cosy social place. It should feel like entering a small game world: scene-first,
compact HUD, object interaction and bounded editing toolbelt. The old large web
headline/card/sidebar composition is superseded; seeADR0003 for actual references.
A game feeling does not require scoring, streaks or grinding.

C8 is a public visitor rehearsal: name/windowcolour, six starter pieces across
four types, one owned lamp pane with optional reason, withdrawal and return.
No invite is needed. Public saving is deliberate and explained. A cookie proves
its owner; losing it creates a new visitor. Private circles, cross-device recovery,
human benefit and real-phone performance are not initial claims.

## Sustainable boundaries

Renderer consumes stable room/placement/part records. HUD, scene and storage do
not own each other's state. Catalogue IDs/versions and full footprints include
fixed obstacles; new models need licence/hash/pivot/scale/variants/old-room checks.
Session identity, command UUID receipt and entity revision serve different jobs.
Commit before confirmation/broadcast; stale identities get explicit recovery.
C8 uses Node24.21.0 and testedSQLite3.53.4 through its RCbinding, a replaceable Store,
bounded SSE full projections, one service and one mounted Flyvolume.
Six pieces are a release slice, not a general construction editor. Append coherent
small catalogues after the loop works; do not silently change old placements.
Saved avatars/windows are not online presence. Later availability/movement needs
opt-in transient leases and its own user-value/network decision.

## Stages and gates

C8: stranger save/return, immersive controls, checks/README/PROCESS/reflection,
real browser, independent review, actual live persistence.
C9: improve simultaneous authored making and recovery, measure deployed delays,
test existing friends' use. Private circles need real membership/read/write/
migration semantics; public C8content does not quietly become confidential.
C10: safe structuredlogs/faultdiagnosis/lifecycle/backup-restore evidence, without
tokens, private note/draft text or online-duration rankings.
Final:12then24catalogue only when art/phone remain usable; second shared template,
semantic occasions/archives with capacity/retraction; real-friends synchronous
and next-day trials; volume restart/redeploy and both viewports.

Free walking, modular avatars, richer building shells and gentle game rituals are
possible later. Each needs feasibility, licence, authority and actual user evidence.
Conditional50h/78h budgets from previous plans are estimates, not guarantees.
Replace an approach if observed requirements/runtime/feedback justify the cost.

## Workflow

Inspect actual files and treat skills/subagents critically. Research changing APIs
from primary docs. Comparisons declare controls/limits; fresh reviewers receive
only needed artifacts. Preserve meaningful failing tests and milestone commits.
Green checks alone establish neither aesthetics nor human connection.
