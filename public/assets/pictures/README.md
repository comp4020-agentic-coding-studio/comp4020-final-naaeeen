# Picture-table artwork

Rain at the study nook is original vector artwork authored with Codex for this
project. It embeds no third-party game artwork, fonts or remote resources. The
shared-puzzle mechanism was researched separately; reference products do not grant
rights to copy their artwork.

Version 1 preserves this SVG and its 24-piece crop mapping. Saved rounds refer to
its ID, version and SHA-256. Add a new version and keep older referenced files when
changing art; do not silently replace the picture behind saved progress.
